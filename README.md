# Autonomous Air Corridor Highway System

Air cell based structured airspace simulation for Advanced Air Mobility.
Stack: PX4 SITL + Gazebo Harmonic + ROS 2 Humble.

## Packages
- `uas_sim` - launch files and nodes (offboard nav, footprint bubble, cell manager)
- `uas_interfaces` - service definitions (ResizeCell)
- `worlds/` - Gazebo world files
- `models/` - custom air cell models

See SETUP_NOTES.md for PX4 / px4_msgs versions and airframe config.
